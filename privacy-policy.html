X PiP Feed — Privacy Policy

Last updated: March 23, 2026

Overview

X PiP Feed is a browser extension that displays posts from your X Following timeline and Donald Trump’s Truth Social page in a Picture-in-Picture window. This policy explains what data the extension accesses and where that data is stored.

Data Collection

X PiP Feed does not collect, store, or transmit user data to any server operated by the developer. Specifically:

  • No analytics or tracking. The extension does not include any analytics, telemetry, or tracking code.
  • No accounts or sign-ups. The extension does not require or create any user accounts.
  • No data sold. User data is not sold to third parties.

Data Accessed Locally

The extension accesses the following data, all of which stays on your device:

  • Website content from X and Truth Social: The extension reads post text, usernames, timestamps, and post URLs so it can render the PiP feed.
  • Extension settings: Preferences such as refresh interval and notification sound settings are stored in Chrome storage.
  • Cached feed state: Recent posts are stored locally in Chrome storage while the PiP session is active so the PiP window can update without using your visible browsing tab as the data source.

Third-Party Services

The extension does not send your feed data to any developer-operated server or analytics service. If you enable translation for selected X accounts, the extension sends those post texts to Google Translate so English translations can be returned. Otherwise, it only loads X and Truth Social pages in the browser so it can read the posts needed for the PiP feed.

Permissions

  • tabs: Used to create, update, and manage the dedicated scraper tabs and to open original posts when clicked from the PiP feed.
  • storage: Used to save settings and locally cached feed data.
  • alarms: Used to refresh the scraper tabs on the configured interval.
  • system.display: Used for positioning the compact PiP popup window when that optional shortcut is used.
  • X and Truth Social host access: Required so the extension can run on those pages, read post content, and show the PiP launch button.

Data Retention

Cached posts are stored locally in Chrome storage only while the PiP session is active, then cleared when the session ends. Settings remain in Chrome storage until changed or removed by the user. Uninstalling the extension removes extension-managed local data from Chrome.

Changes
